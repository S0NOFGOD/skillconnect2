# SKILLCONNECT

SkillConnect is a platform that connects clients with nearby skilled workers, making it easier for people to find and hire reliable professionals within their area.

## Technology Stack

### Frontend
- HTML
- CSS
- JavaScript
- TypeScript
- React
- Vite

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- PostgreSQL
- Prisma ORM
- Supabase

### Development Tools
- Visual Studio Code
- Git
- GitHub
- Postman

### Deployment
- Vercel (Frontend)
- Render (Backend)
- Supabase (Database)
